# Design system

Visual character: quiet, technical, editorial, and deliberate. The source uses a near-monochrome OKLCH scale, sharp edges, thin rules, compact uppercase labels, and restrained motion.

Hierarchy: Outfit body copy; Nunito Sans headings at medium/semibold weights; Geist Mono for metadata and command-like labels. Use contrast and scale before color.

Composition: wide content containers, 14px header rhythm, 16-24px component padding, borders instead of elevation, and no decorative rounded corners. Primary actions are dark/light inversions; destructive actions are a muted red tint.

Responsive: preserve sparse navigation and hide secondary controls before reducing touch target sizes. Respect reduced motion. Dialogs are full width minus 2rem up to a medium width.

Do: use semantic surfaces, bottom-rule inputs, and concise labels. Don't: introduce gradients, soft cards, pill buttons, or saturated decorative colors. Inference: source typography pair is product-specific but its three-role hierarchy is portable.
